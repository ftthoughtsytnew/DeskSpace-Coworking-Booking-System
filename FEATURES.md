# Feature scope

## Configured business
- Space type: Open coworking space
- Capacity: 50 seats
- Location: Delhi NCR
- Durations: Hourly, daily, monthly
- Payment options: Online payment (integration pending) and pay at office
- Confirmation: Automatic after booking record is created
- Documents: Only when required; private upload implementation pending

## Current starter implementation
- Marketing homepage
- 50-seat visual selector
- Booking date and duration inputs
- Customer name, email and phone
- Payment preference selection
- Supabase RPC call for booking creation
- PostgreSQL overlap constraint
- Admin dashboard placeholder

## Not yet implemented
- Real-time seat availability display by date/time
- Admin login and authorization
- Admin CRUD screens
- Payment gateway checkout and webhook
- Secure document upload and review
- Email/WhatsApp notifications
- Cancellation/refunds and customer self-service
- Production monitoring and deployment configuration
